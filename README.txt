BATTLEXA PWA — FREE STARTER MVP

WHAT THIS IS
- Responsive gaming tournament website with installable PWA support.
- Android users can open it in Chrome and install it from the browser menu (or use the Install app prompt where supported).
- Includes sample BGMI and Free Fire MAX tournaments, filters, local demo player profile, local join action, and local organizer form.

IMPORTANT LIMITATIONS
This is a front-end prototype. Data is stored in the browser's localStorage on one device only.
It does NOT provide real shared accounts, server-side tournament slots, secure admin login, payments, refunds, room ID/password delivery, anti-cheat, or real tournament operations.
Do not collect real player payments or publish real room credentials with this demo.

FREE DEPLOYMENT
1. Create a GitHub account and a new repository named battlexa.
2. Upload all files from this folder to the repository root.
3. In GitHub, open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
5. GitHub Pages will provide a public URL. The first deployment may take a few minutes.
Alternative: import the repository into Cloudflare Pages or Vercel free tier.

INSTALL ON ANDROID
Open the deployed URL in Chrome > browser menu (three dots) > Install app / Add to Home screen.
